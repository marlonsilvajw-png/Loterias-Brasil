# 🎱 Loterias Brasil

Plugin para consultar resultados, conferir apostas e analisar estatísticas das loterias brasileiras.

## Modalidades
- Mega-Sena
- Lotofácil
- Quina
- Lotomania

## Funcionalidades
- Consulta de resultados
- Conferência de apostas
- Estatísticas históricas

## Status
Em desenvolvimento.

Projeto independente, sem vínculo oficial com a CAIXA.
